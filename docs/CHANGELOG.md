# Changelog

## [1.1.0] - 2026-01-26

### Добавлено
- ✅ **Полная интеграция с Management API**
- ✅ **Правила использования VPN:**
  - Документ TERMS_OF_SERVICE.md с полными правилами
  - Автоматическая отправка правил при /start для клиентов
  - Команда /terms для просмотра полных правил
  - Система предупреждений (3 уровня)
  - Запрет на торренты, передачу ключа, незаконную деятельность
- ✅ **Команды администратора:**
  - `/add_client` - интерактивное добавление клиента через API
  - `/remove_client` - удаление клиента с inline кнопками
  - `/list_clients` - список всех клиентов с деталями (подписка, трафик)
  - `/client_info <uuid>` - детальная информация о клиенте
  - `/server_status` - статус сервера и статистика
- ✅ **Команды клиента:**
  - `/my_vpn` - статистика VPN с подпиской и трафиком
  - `/my_link` - информация о UUID (ссылка генерируется на сервере)
  - `/my_requests` - история запросов на продление
- ✅ **Система запросов на продление:**
  - Клиент выбирает период (1-12 месяцев)
  - Админ получает уведомление с inline кнопками
  - Одобрение/отказ/изменение периода через API
  - Автоматическое продление подписки при одобрении
  - Уведомления клиенту о решении
- ✅ **Кнопки в главном меню:**
  - Админ: 👥 Клиенты, 📊 Статистика, 📝 Запросы, ⚙️ Сервер
  - Клиент: 📊 Мой VPN, 🔗 Моя ссылка, 🔑 Запросить ключ, 📝 Мои запросы
- ✅ **Обработка состояний пользователя** для интерактивных команд
- ✅ **Связывание Telegram ID с UUID клиента**
- ✅ **Документация по тестированию** (docs/TESTING.md)

### Изменено
- Обновлена структура обработчиков команд
- Улучшена обработка ошибок API
- Добавлены детальные сообщения об ошибках
- Обновлен CHANGELOG.md

### Исправлено
- Корректная обработка callback query для запросов на продление
- Правильное отображение дат и периодов подписки
- Обработка клиентов без Telegram ID

### Технические детали
- Интеграция с 22 API endpoints
- Полная поддержка CRUD операций для клиентов
- Автоматическое продление подписки через API
- Обработка ошибок с информативными сообщениями

## [1.0.0] - 2026-01-25

### Добавлено
- ✅ Базовая структура Telegram бота
- ✅ Обработчики команд для администратора (/start, /help)
- ✅ Обработчики команд для клиента (/start, /help)
- ✅ Система запросов на продление подписки (заглушки)
- ✅ Inline кнопки для одобрения/отказа запросов
- ✅ SSH утилита для подключения к VPN серверу
