# Руководство по тестированию

## Подготовка к тестированию

### 1. Запуск Management API (первый репозиторий)

```bash
# В корне первого репозитория (xray-vpn-server)
cd /path/to/xray-vpn-server

# Установить зависимости
npm install

# Инициализировать базу данных
sqlite3 database/vpn.db < database/init.sql

# Запустить API сервер
node api/server.js
```

API будет доступен на `http://localhost:3000`

### 2. Запуск Telegram бота (второй репозиторий)

```bash
# В папке yaronetworktool
cd yaronetworktool

# Установить зависимости
npm install

# Проверить .env файл
cat .env

# Запустить бота
node bot/yaronetworktool_bot.js
```

## Тестирование функционала

### Тест 1: Команды администратора

1. **Запуск бота**
   - Отправьте `/start` от имени администратора
   - Должно появиться админ меню с кнопками

2. **Добавление клиента**
   - Отправьте `/add_client`
   - Введите имя: `Test Client`
   - Введите Telegram ID: `123456789` (или `0` если не известен)
   - Введите количество дней: `30`
   - Должно появиться сообщение об успешном создании с UUID

3. **Список клиентов**
   - Нажмите кнопку `👥 Клиенты` или отправьте `/list_clients`
   - Должен появиться список всех клиентов с деталями

4. **Информация о клиенте**
   - Отправьте `/client_info <UUID>` (UUID из предыдущего шага)
   - Должна появиться детальная информация о клиенте

5. **Статус сервера**
   - Нажмите кнопку `⚙️ Сервер` или отправьте `/server_status`
   - Должна появиться статистика сервера

6. **Удаление клиента**
   - Отправьте `/remove_client`
   - Выберите клиента из списка
   - Подтвердите удаление

### Тест 2: Команды клиента

1. **Регистрация клиента**
   - Создайте клиента через `/add_client` с вашим Telegram ID
   - Или обновите существующего клиента в базе данных:
     ```sql
     UPDATE clients SET telegram_id = YOUR_TELEGRAM_ID WHERE uuid = 'CLIENT_UUID';
     ```

2. **Запуск бота от имени клиента**
   - Отправьте `/start` от имени клиента
   - Должно появиться клиентское меню

3. **Моя статистика VPN**
   - Нажмите кнопку `📊 Мой VPN` или отправьте `/my_vpn`
   - Должна появиться статистика: подписка, трафик, статус

4. **Моя ссылка**
   - Нажмите кнопку `🔗 Моя ссылка` или отправьте `/my_link`
   - Должна появиться информация о UUID (ссылка генерируется на сервере)

5. **Мои запросы**
   - Нажмите кнопку `📝 Мои запросы` или отправьте `/my_requests`
   - Должен появиться список запросов (пустой если нет запросов)

### Тест 3: Запросы на продление

1. **Создание запроса от клиента**
   - Нажмите кнопку `🔑 Запросить ключ`
   - Выберите период: `3 месяца`
   - Должно появиться подтверждение отправки

2. **Получение уведомления админом**
   - Администратор должен получить уведомление с inline кнопками
   - Кнопки: `✅ Разрешить`, `❌ Отказать`, `📝 Другой период`

3. **Одобрение запроса**
   - Нажмите `✅ Разрешить`
   - Должно появиться подтверждение одобрения
   - Клиент должен получить уведомление об одобрении
   - Проверьте `/my_vpn` - подписка должна быть продлена

4. **Отказ в запросе**
   - Создайте новый запрос
   - Нажмите `❌ Отказать`
   - Клиент должен получить уведомление об отказе

5. **Изменение периода**
   - Создайте новый запрос
   - Нажмите `📝 Другой период`
   - Введите количество дней: `45`
   - Подписка должна быть продлена на 45 дней

### Тест 4: Проверка API напрямую

Используйте curl для проверки API endpoints:

```bash
# Получить список клиентов
curl http://localhost:3000/api/v1/clients

# Получить информацию о клиенте
curl http://localhost:3000/api/v1/clients/<UUID>

# Создать запрос на продление
curl -X POST http://localhost:3000/api/v1/extension-requests/create \
  -H "Content-Type: application/json" \
  -d '{"client_uuid":"<UUID>","telegram_id":123456789,"requested_months":3}'

# Получить все запросы
curl http://localhost:3000/api/v1/extension-requests

# Одобрить запрос
curl -X POST http://localhost:3000/api/v1/extension-requests/<ID>/approve \
  -H "Content-Type: application/json" \
  -d '{"admin_telegram_id":137981675}'
```

## Известные ограничения

1. **Генерация ссылок подключения** - требует интеграции с CLI скриптами на VPN сервере
2. **Мониторинг трафика** - требует парсера логов X-Ray (Task 13)
3. **Автоматическая блокировка** - требует cron задач (Task 12)
4. **Резервное копирование** - требует скриптов бэкапа (Task 14)

## Troubleshooting

### Бот не отвечает
- Проверьте TELEGRAM_BOT_TOKEN в .env
- Проверьте подключение к интернету
- Проверьте логи: `node bot/yaronetworktool_bot.js`

### API не работает
- Проверьте что API запущен: `curl http://localhost:3000/health`
- Проверьте порт в .env (API_PORT=3000)
- Проверьте логи API сервера

### База данных не найдена
- Инициализируйте базу: `sqlite3 database/vpn.db < database/init.sql`
- Проверьте путь DB_PATH в .env

### Клиент не зарегистрирован
- Добавьте клиента через `/add_client`
- Или обновите telegram_id в базе данных
